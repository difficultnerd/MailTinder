## Goal

The template's single `backend` crate becomes a Cargo workspace with one empty crate per entry in the CONVENTIONS layout, shared lint settings and shared dependency versions. Every later Rust task adds code to one of these crates instead of inventing its own layout. CI (`rust`, `cargo-audit`, `cargo-deny`) keeps passing on the new workspace.

## Algorithm

1. Delete `backend/src/main.rs` and the `[package]`, `[dependencies]`, `[lints.*]` sections of `backend/Cargo.toml`; write the workspace manifest above.
2. Create the 13 crate folders under `backend/crates/` with the manifests and stub sources above. Package names use hyphens exactly as in the CONVENTIONS layout; Rust code refers to them with underscores (`adapters_gmail`).
3. Write `backend/crates/domain/tests/inv_7.rs` (below).
4. Run `cd backend && cargo generate-lockfile && cargo fmt --all && cargo clippy --all-targets --all-features --locked -- -D warnings && cargo test --all-features --locked`. Commit the new `Cargo.lock`.
5. Run `cargo deny --manifest-path backend/Cargo.toml check` locally if `cargo-deny` is installed; otherwise rely on the CI job.

## Tests that must pass

- `inv_7_domain_depends_on_no_io_or_provider_crates` (unit, `domain`, integration test file `tests/inv_7.rs`)
- The existing CI jobs `rust`, `cargo-audit`, `cargo-deny` on the new workspace.

## Edge cases and traps

- A virtual workspace needs `resolver = "2"` written out; without it Cargo warns and edition 2021 crates resolve features differently.
- Every crate must set `publish.workspace = true` (so `publish = false`). `deny.toml` skips licence checks only for unpublished private crates; a crate without it fails `cargo-deny` as `UNLICENSED`.
- Commit `Cargo.lock`. CI runs `cargo clippy --locked` and `cargo test --locked`, which fail if the lock file is stale or missing.
- `[lints] workspace = true` must be in every crate; otherwise the clippy settings silently stop applying to it.
- Clippy `pedantic` is a warning and `-D warnings` makes it an error. Fix the lint; never add `#[allow(...)]` (S13 4.6).
- Do not use `unwrap` or `expect` in the test; return `Result` and use `?` or `ok_or`.
- Do not add `tokio`, `axum` or `reqwest` to any crate yet. Unused workspace dependencies are never resolved, so they cost nothing until a task opts in.
- Binaries print nothing. `println!` is banned once T-003 installs the privacy layer, so do not start a habit of it here.
- Do not add a `backend/src/` folder back; the workspace root is manifest only.
